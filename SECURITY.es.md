# Política de seguridad

[English](SECURITY.md) · Español

## Reportar una vulnerabilidad
No abras un issue público. Usa **GitHub → Security → Report a vulnerability** (un aviso privado) en este repositorio.
Primera respuesta: mejor esfuerzo, con un objetivo de 5 días hábiles. Divulgación coordinada: 90 días o hasta publicar la corrección, lo que ocurra primero.

## Alcance
Fuga de credenciales, ejecución de código desde webviews, evasión del modo de solo lectura o de las políticas, inyección SQL en el SQL generado y problemas de la cadena de suministro.

## Versiones soportadas
Solo la última versión publicada.
