# RizomaDB

A free, Apache-2.0 database client for VS Code, VSCodium, Cursor and Windsurf. No telemetry, no paid tiers.

> **Status: pre-1.0.** Nothing is published yet. See the [honest comparison](/en/market/honest-comparison) for what works and what does not.

## What works today
- Engines tested against real servers: SQLite, PostgreSQL, MySQL/MariaDB, SQL Server, Oracle, MongoDB, Redis/Valkey, ClickHouse, Elasticsearch/OpenSearch, DuckDB (see the [support matrix](/en/engines/README)).
- Queue-based data editing, schema designer and diff, ER diagrams, import/export, data compare/sync.
- Enterprise controls: layered policy, local audit, shared catalogs without secrets ([policy](/en/enterprise/policy)).
- Opt-in AI (schema only) and a read-only MCP server.

## Not done
