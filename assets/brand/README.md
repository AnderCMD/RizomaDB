# RizomaDB brand

English · [Español](README.es.md)

**Meaning.** A database cylinder with roots (a rhizome) reaching three nodes: many databases connected without a hierarchy. The amber node marks the "origin point" of the connection.

**Chosen concept** (of 3 evaluated): (1) a cylinder with roots, chosen because it reads as both "database" and "network" at 16 px; (2) a pure node network, discarded for looking like a generic graph; (3) an "R" monogram, discarded for not conveying the concept.

## Files
All are generated with `pnpm build:brand` (`scripts/build-brand.mjs`); do not edit them by hand.
`logo-mark.svg`, `logo-mark-mono.svg`, `logo-horizontal-light.svg`, `logo-horizontal-dark.svg`, `favicon.svg`, `icon-128.png`, `icon-256.png`, `social-preview-1280x640.png`.
The legibility sheet (16/32/64/128 px on light and dark) is generated in `_proof/` and is not published.

## Palette and contrast (checked by script on every build)
Navy `#0F172A`, mint `#34D399`, white `#FFFFFF`, amber `#FBBF24`. See [_contrast.md](_contrast.md): graphics ≥ 3:1, text ≥ 4.5:1; the build fails if that is not met.

## Typography
The wordmark is **Inter Bold** (SIL OFL 1.1 licence), converted to outlines: the SVGs do not depend on fonts.

## Usage
- Clear space: at least 1/4 of the symbol's width on every side.
- Minimum size: symbol 16 px; horizontal logo 96 px wide for the text.
- Do not: recolour outside the palette, stretch, rotate, add shadows, separate "Rizoma" and "DB" or write it in lower case ("RizomaDB" always).
- Licence of the assets: Apache-2.0, like the project.
