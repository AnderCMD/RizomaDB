# Settings reference

Every setting of the extension. Open the settings screen with **RizomaDB: Open Settings** to change them with a form; each change is saved to your user settings as you make it. Settings marked *machine-overridable* can also be set by an administrator.

| Setting | Type | Default | What it does |
|---|---|---|---|
| `rizomadb.language` | string (`auto`, `en`, `es`, `pt`, `fr`) | `auto` | Language of the RizomaDB screens and messages: `auto` follows the VS Code display language, or force `en`, `es`, `pt` (Português, Brasil) or `fr`. Command and setting names always follow VS Code. |
| `rizomadb.environments` | list | `[]` | Extra environments next to dev, staging and prod, e.g. `{ "name": "qa", "protection": "confirm" }`. Protection: `none`, `confirm` (ask before every write) or `readOnly` (block writes). Add one from the New connection screen too. |
| `rizomadb.editor.codeLens` | boolean | `true` | Show Run and Explain buttons above each statement in query editors, plus Run all and the connection in use. |
| `rizomadb.editor.highlightStatement` | boolean | `true` | Highlight the statement under the cursor in query editors. |
| `rizomadb.explorer.groupByFamily` | boolean | `true` | Group the connections in the tree by engine type (relational, document, key-value…). |
| `rizomadb.results.location` | string (`bottom`, `full`, `beside`) | `bottom` | Where query results and opened tables appear: `bottom` (lower half under the editor, default), `full` (the whole editor area) or `beside` (next to the editor). |
| `rizomadb.security.confirmDestructive` | boolean | `true` | Ask for confirmation before destructive statements (DROP, TRUNCATE, UPDATE/DELETE without WHERE). Read-only blocking is never affected by this setting. |
| `rizomadb.security.prodReadOnlyByDefault` | boolean | `true` | Treat connections tagged `prod` as read-only. |
| `rizomadb.query.pageSize` | number | `1000` | Rows loaded per page of query results. "Load more" in the results view fetches the next page on every engine. |
| `rizomadb.query.maxRows` | number | `100000` | Maximum rows kept in one result view across all loaded pages. |
| `rizomadb.query.timeoutSeconds` | number | `0` | Query timeout in seconds (0 = none). |
| `rizomadb.history.enabled` | boolean | `true` | Record executed statements in a local history file (secrets are redacted). |
| `rizomadb.history.retentionDays` | number | `90` | Days to keep history entries. |
| `rizomadb.edit.applyImmediately` | boolean | `false` | Save each cell edit as soon as you confirm it, without pressing Apply. On `dev` connections it applies silently; every other environment still asks first, and policies and read-only rules always apply. |
| `rizomadb.table.openRows` | number | `200` | Rows loaded when opening a table. |
| `rizomadb.policy.team` | object | `{}` | Team policy layer (same format as `.rizomadb/policy.json`). Deploy it through managed VS Code settings; project and user layers can only make it stricter. |
| `rizomadb.catalog.teamFile` | string | *(empty)* | Path of a shared connection catalog file (no secrets). |
| `rizomadb.audit.enabled` | boolean | `true` | Write a local audit trail of every statement (literals are removed). |
| `rizomadb.audit.path` | string | *(empty)* | Audit file path (default: the extension's storage folder). |
| `rizomadb.audit.includeValues` | boolean | `false` | Keep literal values in audit entries. Off by default so the log holds no data. |
| `rizomadb.mcp.autoRegister` | boolean | `false` | Offer the read-only RizomaDB MCP server to VS Code's MCP client when a folder has `.rizomadb/mcp.json` (made by *RizomaDB: Generate MCP Configuration*). Off by default; the database password is asked when the server starts. |
| `rizomadb.ai.enabled` | boolean | `false` | Turn on AI assistance. Off by default: nothing is sent anywhere until you enable it and confirm each remote request. |
| `rizomadb.ai.provider` | string (`openai-compatible`, `anthropic`) | `openai-compatible` | API style: `openai-compatible` (Ollama, LM Studio, OpenAI, …) or `anthropic`. |
| `rizomadb.ai.endpoint` | string | `http://localhost:11434/v1` | Base URL of the model API. Local endpoints (localhost) send nothing off your machine. |
| `rizomadb.ai.model` | string | `llama3.1` | Model name to request. |
| `rizomadb.ai.redactLiterals` | boolean | `true` | Replace literal values in your SQL with `?` before it is included in a request. |

*Generated by `scripts/gen-reference.mjs` from the extension manifest; do not edit by hand.*
