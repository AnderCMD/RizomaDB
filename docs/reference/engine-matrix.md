## Notes

- **Table filter box**: the bar under the query line when you open a table; it changes the statement in the database, so paging and editing keep working.
- **Column edits**: rename, change type, NOT NULL, default, add and drop from the column menu; they show the exact DDL and ask for confirmation.
- **Read-only enforced by the server** means the connection itself refuses writes; by RizomaDB (client) means a default-deny statement classifier does, so for a hard guarantee also use a read-only database role.
