# ADR 0001 — Nombre: RizomaDB

Estado: aceptada (2026-10-20)

## Verificación de disponibilidad (hoy)
- npm `rizomadb`: libre (404). GitHub: 0 repos con ese nombre. VS Code Marketplace: 0 resultados. Open VSX: 0 resultados.
- Nombres de respaldo no usados.

## Riesgo de confusión
Existe **RhizomeDB** (GitHub: `RhizomeDB/*`, `mbilokonsky/rhizomedb`), motor/proyecto de BD. Se distingue por escritura (Rizoma vs Rhizome) e idioma; el riesgo de búsqueda existe pero es bajo, ya que el producto es un cliente, no un motor. Mitigación: tagline "Database Client" en `displayName`, keywords propias.

## Decisión
Usar **RizomaDB**. No se ha hecho búsqueda de marcas registradas formal; recomendado antes de v1.0.
