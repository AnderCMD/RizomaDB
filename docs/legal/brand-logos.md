# Engine logos

The "New connection" screen shows each database engine with its brand mark so people can recognise it.

- **Sources:** `apps/extension/src/engineLogos.ts` is generated by `scripts/gen-logos.mjs` from [simple-icons](https://github.com/simple-icons/simple-icons) 16.35.0 (CC0-1.0), [gilbarbara/logos](https://github.com/gilbarbara/logos) via `@iconify-json/logos` (CC0-1.0: Oracle, DynamoDB, Valkey, YugabyteDB) and [devicon](https://github.com/devicons/devicon) (MIT: SQL Server). Only allow-listed SVG elements and attributes are kept.
- **Trademarks:** The licences cover the files, not the marks. Product names and logos belong to their owners (PostgreSQL Community Association, Oracle, Oracle/MySQL, MariaDB Foundation, MongoDB Inc., Redis Ltd., Elastic, Neo4j, InfluxData, ClickHouse, and others). RizomaDB uses them only to identify the matching engine and is **not affiliated with, endorsed by or sponsored by** any of them. The screen says so.
- **Fallback:** an engine with no entry in `ENGINE_LOGOS` shows an original RizomaDB monogram tile. All 24 engines currently have a logo.
- **Removing a logo:** delete its entry from `ENGINE_LOGOS`; the screen falls back to the monogram tile. Do this promptly if an owner asks.
- **Review:** this is a nominative-use judgement, not legal advice. Have someone qualified confirm it before the first public release.
