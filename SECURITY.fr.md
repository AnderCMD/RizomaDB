# Politique de sécurité

[English](SECURITY.md) · [Español](SECURITY.es.md) · [Português (Brasil)](SECURITY.pt-br.md) · Français

## Signaler une vulnérabilité
N'ouvrez pas d'issue publique. Utilisez **GitHub → Security → Report a vulnerability** (un avis privé) dans ce dépôt.
Première réponse : au mieux, avec un objectif de 5 jours ouvrés. Divulgation coordonnée : 90 jours ou jusqu'à la publication d'un correctif, selon ce qui arrive en premier.

## Périmètre
Fuite d'identifiants, exécution de code depuis des webviews, contournement du mode lecture seule ou des politiques, injection SQL dans le SQL généré et problèmes de chaîne d'approvisionnement.

## Versions prises en charge
Uniquement la dernière version publiée (le projet est en pré-alpha et rien n'est encore publié).
