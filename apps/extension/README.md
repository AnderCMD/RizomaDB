# RizomaDB — Database Client

**English** · [Español](#español)

Free, open-source database client for VS Code (Apache-2.0). No telemetry, no accounts, no locked features. 24 engines, an editable results grid, layered policies and an audit trail. Documentation and source: <https://github.com/AnderCMD/RizomaDB>.

> Pre-release: not published yet. Cloud services (AWS, Google Cloud, Atlas, managed PostgreSQL/MySQL) have never been tested: try a read-only user first.

## Español
Cliente de bases de datos gratuito y de código abierto para VS Code (Apache-2.0). Sin telemetría, sin cuentas, sin funciones bloqueadas. 24 motores, una rejilla de resultados editable, políticas en capas y registro de auditoría. Documentación y código: <https://github.com/AnderCMD/RizomaDB>.

> Pre-lanzamiento: aún sin publicar. Los servicios en la nube (AWS, Google Cloud, Atlas, PostgreSQL/MySQL gestionados) nunca se han probado: prueba primero con un usuario de solo lectura.
