## Relatar uma vulnerabilidade
Não abra um issue público. Use **GitHub → Security → Report a vulnerability** (um aviso privado) neste repositório.
Primeira resposta: melhor esforço, com meta de 5 dias úteis. Divulgação coordenada: 90 dias ou até a correção ser publicada, o que ocorrer primeiro.

## Escopo
Vazamento de credenciais, execução de código a partir de webviews, contorno do modo somente leitura ou das políticas, injeção de SQL no SQL gerado e problemas na cadeia de suprimentos.

## Versões suportadas
Somente a última versão publicada (o projeto é pré-alfa e nada foi publicado ainda).
