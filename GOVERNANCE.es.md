# Gobierno

[English](GOVERNANCE.md) · Español

El proyecto lo mantienen sus autores (un modelo de dictador benevolente). Las decisiones técnicas se toman en abierto, en issues y pull requests. Ninguna función se bloqueará nunca tras un pago o una cuenta. La financiación, si la hay, es por patrocinios opcionales.
