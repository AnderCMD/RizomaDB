# Gobierno

[English](GOVERNANCE.md) · Español · [Português (Brasil)](GOVERNANCE.pt-br.md) · [Français](GOVERNANCE.fr.md)

El proyecto lo mantienen sus autores (un modelo de dictador benevolente). Las decisiones técnicas se registran como ADR en [docs/adr](docs/adr) (escritos en español, el idioma de trabajo del proyecto). Ninguna función se bloqueará nunca tras un pago o una cuenta. La financiación, si la hay, es por patrocinios opcionales.
